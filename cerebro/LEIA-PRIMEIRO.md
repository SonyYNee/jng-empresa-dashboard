# Cérebro do projeto JNG

Registro de continuidade preparado em **17/09/2026**. Leia este arquivo primeiro ao retomar o projeto em outro computador.

## Mensagem para o próximo assistente

> Leia `AGENTS.md` e todos os documentos públicos de `cerebro/`, começando por este índice. Consulte o histórico privado apenas quando precisar de evidência exata. Preserve as decisões registradas, verifique o estado atual do Git e da Vertra antes de agir e continue o projeto existente. Não recrie a aplicação do zero. Não exponha nem versione o conteúdo de `cerebro/privado/`.

## O que significa “tudo” neste backup

Este registro combina a conversa disponível, os arquivos atuais, o histórico Git e as sessões locais do Codex identificadas pelo diretório do projeto. Os registros brutos ficam no backup privado, incluindo ferramentas, erros e referências visuais que estejam efetivamente presentes nas sessões. Não há garantia de recuperar mensagens que o aplicativo não gravou, anexos já removidos ou informações que nunca foram fornecidas. O inventário informa exatamente quais fontes foram preservadas.

As decisões abaixo não substituem a inspeção do código: quando houver divergência, identifique a data e a evidência antes de modificar o comportamento. Relatos antigos e instruções superadas estão identificados como históricos.

## Antes de formatar o computador

**Copie `cerebro/privado/` para um disco externo ou armazenamento privado fora deste PC.** Uma cópia na mesma unidade será perdida na formatação. A documentação pública e o código podem ser recuperados pelo GitHub; o backup privado fica intencionalmente fora do Git e contém dados e credenciais sensíveis.

Não publique o ZIP privado. Ele preserva contexto bruto e arquivos de acesso e não deve ser tratado como um artefato público. Confira o manifesto e os hashes do backup antes de apagar o sistema.

## Atualização futura

Ao concluir mudanças relevantes, registre aqui a decisão, o motivo, os arquivos afetados, a validação executada, o commit e se a alteração foi publicada. Não apague incidentes antigos: marque-os como resolvidos ou superados. Atualize o estado corrente e mantenha a cronologia consultável.
